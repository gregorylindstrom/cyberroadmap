// Lab readiness check

Can your laptop
run the labs?

Hands-on cybersecurity work means virtual machines, Kali Linux, and Docker containers — and not every laptop is up to it. This two-stage check tells you in about two minutes, before you're stuck mid-course on a machine that can't keep up.

// Stage 2 · Full check

The checks that matter most.

Virtualization support, exact RAM, and free disk space aren't visible to browsers. Copy the one-line command for your operating system, run it, and paste the result back here. The command only reads system information — it changes nothing, installs nothing, and sends nothing anywhere. Don't take my word for it: expand the breakdown below each command and read exactly what it does. Never run commands you don't understand — that habit will serve you well in this field.

1 · Open PowerShell (Start menu → type "powershell" → Enter — no administrator needed), paste this single line, press Enter:
$c=Get-CimInstance Win32_ComputerSystem;$p=Get-CimInstance Win32_Processor|Select-Object -First 1;$o=Get-CimInstance Win32_OperatingSystem;"CRC1|OS:WIN|RAM:$([math]::Round($c.TotalPhysicalMemory/1GB))|CORES:$($p.NumberOfLogicalProcessors)|CPU:$($p.Name -replace '\|',' ')|VTFW:$($p.VirtualizationFirmwareEnabled)|HV:$($c.HypervisorPresent)|DISKFREE:$([math]::Round((Get-PSDrive C).Free/1GB))|ARCH:$($env:PROCESSOR_ARCHITECTURE)|OSV:$($o.Caption -replace '\|',' ')"
What does this command do? (read before running)

Get-CimInstance Win32_ComputerSystem / Win32_Processor / Win32_OperatingSystem — asks Windows for its standard hardware/OS inventory. Read-only, the same data Task Manager shows.

TotalPhysicalMemory/1GB — your installed RAM, converted to gigabytes.

VirtualizationFirmwareEnabled — whether VT-x/AMD-V is switched on in your BIOS/UEFI. HypervisorPresent — whether Hyper-V is running (also fine for labs).

(Get-PSDrive C).Free/1GB — free space on your C: drive.

The final line prints one text string starting with CRC1. Nothing is written, changed, or transmitted — the string appears only in your terminal until you choose to paste it here.

1 · Open Terminal (Cmd+Space → type "terminal" → Enter), paste this single line, press Enter:
echo "CRC1|OS:MAC|RAM:$(($(sysctl -n hw.memsize)/1073741824))|CORES:$(sysctl -n hw.logicalcpu)|CPU:$(sysctl -n machdep.cpu.brand_string | tr '|' ' ')|ARCH:$(uname -m)|VTX:$(sysctl -n kern.hv_support 2>/dev/null || echo 0)|DISKFREE:$(df -g / | awk 'NR==2{print $4}')|OSV:$(sw_vers -productVersion)"
What does this command do? (read before running)

sysctl -n hw.memsize / hw.logicalcpu / machdep.cpu.brand_string — reads installed RAM, CPU core count, and CPU model from the kernel's public info. Read-only.

uname -m — your architecture: arm64 means Apple Silicon (M-series), x86_64 means Intel.

kern.hv_support — whether the Mac supports the Hypervisor framework needed for VMs.

df -g / — free space on your startup disk. sw_vers — your macOS version.

It all feeds one echo that prints a single CRC1 string to your terminal. Nothing is modified or sent anywhere.

1 · Open a terminal, paste this single line, press Enter:
echo "CRC1|OS:LINUX|RAM:$(free -m | awk '/^Mem:/{printf "%.0f", $2/1024}')|CORES:$(nproc)|CPU:$(lscpu | sed -n 's/^Model name:[ ]*//p' | tr '|' ' ' | head -1)|VTX:$(grep -cE 'vmx|svm' /proc/cpuinfo)|DISKFREE:$(df -BG --output=avail / | awk 'NR==2{gsub(/G| /,""); print}')|ARCH:$(uname -m)"
What does this command do? (read before running)

free -m — installed RAM. nproc — logical CPU count. lscpu — CPU model name.

grep -cE 'vmx|svm' /proc/cpuinfo — counts CPU virtualization flags: vmx is Intel VT-x, svm is AMD-V. Zero means disabled or unsupported.

df -BG / — free space on your root filesystem. uname -m — architecture.

One echo, one printed string, read-only throughout. Nothing leaves your machine.

// If you came up short

A failing check isn't the end.

Virtualization disabled is usually a two-minute BIOS fix, not a hardware problem — the results above will walk you through it. Genuinely underpowered machine? RAM is often upgradeable for under $50 on older laptops, refurbished business laptops (ThinkPad T-series, Dell Latitude) meeting the preferred spec run $250–400, and browser-based platforms like TryHackMe cover early coursework while you save up. If money is the barrier, the scholarships page lists emergency technology grants that exist for exactly this situation.
